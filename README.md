# Android Security & Alarm App

An Android application built in **Android Studio** focused on smart alarm handling, facial behavior checks, voice interaction, and security alerts.

## Key Features
- **Facial Detection:** Eye-open and smile detection for alarm/interaction flows.
- **Voice Interaction:** Hands-free / voice-assisted response capability.
- **Security & Intrusion Capture:** Captures a photo on incorrect PIN or pattern attempts.
- **Automated WhatsApp Alerts:** Sends automated alerts to designated family contacts.

## Tech Stack & Tools
- **Platform:** Android (Android Studio)
- **Language & Components:** Mobile UI/UX, Camera & Media APIs, Voice & Detection modules, Messaging integration
